# Aayvu marketing website

Static marketing site for [aayvu.io](https://aayvu.io).

## Deployment

Production is hosted on Cloudflare Pages and connected directly to the
`SurveyBuilderLLM/website` GitHub repository. A push to `main` triggers a
production deployment; other branches receive preview deployments.

Cloudflare Pages build settings:

- Production branch: `main`
- Framework preset: None
- Build command: leave blank
- Build output directory: `/`

The Pages project serves `aayvu.io`, `www.aayvu.io`, and `web.aayvu.io`.
`aayvu.io` is the canonical hostname used in page metadata.

## Current homepage direction (2026-10-01)

The homepage now uses an editorial research-workbench system: an asymmetric
hero, a scrollable six-page source questionnaire connected to a fully
interactive respondent preview, an explicit four-stage process, a shared-scale
time-savings calculator, and a keyboard-accessible feature workbench. Feature
demos include agent commands, question-type selection, QA, live theme colors,
translations, quota sliders, and role permissions. Motion is used to reveal
process and content state while honoring reduced-motion preferences.

The homepage survey also demonstrates live questionnaire logic: Q2 pipes a
selected brand into Q3, and the Q3 rating controls whether the pricing or
open-text follow-up branch is shown. Use-case detail pages rotate through three
study-specific question cards. Every feature detail page has its own contextual
mini-interface rather than a shared generic hero graphic.

## Preview and themes

Open `index.html` to preview the site. Use the moon/sun button in the navbar
to switch between light and dark mode. Light mode is the default; your choice
is saved in browser storage and carried across pages when storage is available.
The amber brand colors are shared by both themes. Google Fonts requires an
internet connection; system fonts are used otherwise.

`theme.css` contains dark surface styles and the toggle styling. `theme.js`
applies the saved theme before rendering. `navigation.js` handles the dropdowns.
Run `python3 build.py` to regenerate the 15 detail pages after editing their
content or shared navbar template.
