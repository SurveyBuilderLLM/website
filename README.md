# Aayvu marketing site — mockups (draft)

## Preview and themes

Open `index.html` to preview the site. Use the moon/sun button in the navbar
to switch between light and dark mode. Light mode is the default; your choice
is saved in browser storage and carried across pages when storage is available.
The amber brand colors are shared by both themes. Google Fonts requires an
internet connection; system fonts are used otherwise.

`theme.css` contains dark surface styles and the toggle styling. `theme.js`
applies the saved theme before rendering. `navigation.js` handles the dropdowns.
Run `python3 build.py` to regenerate the 14 detail pages after editing their
content or shared navbar template.

Static HTML mockups for the new marketing site, built 2026-09-26.
